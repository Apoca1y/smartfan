═══════════════════════════════════════════
引脚分配速查表
═══════════════════════════════════════════

PA0  → PWM输出          (TIM2_CH1, 电机调速)
PA1  → GPIO输出         (TB6612 AIN1)
PA2  → GPIO输出         (TB6612 AIN2)
PA4  → ADC输入          (MQ-2气体传感器)
PA9  → USART1_TX        (ESP8266)
PA10 → USART1_RX        (ESP8266)
PB6  → I2C1_SCL(硬件)   (AHT20/SHT30温湿度传感器)
PB7  → I2C1_SDA(硬件)   (AHT20/SHT30温湿度传感器)
PB8  → I2C_SCL(软件)    (OLED显示屏)
PB9  → I2C_SDA(软件)    (OLED显示屏)
PB13 → GPIO输入(上拉)   (按键K2 - 风力调节)
PB14 → GPIO输入(上拉)   (按键K1 - 模式切换/报警确认)
PB11 → GPIO输入(下拉)   (HC-SR501人体红外传感器)
PB12 → GPIO输出         (有源蜂鸣器，低电平触发)

═══════════════════════════════════════════
编译步骤
═══════════════════════════════════════════

1. 打开Keil MDK
2. File → Open Project
3. 选择：Project.uvprojx
4. 点击编译按钮（F7）
5. 检查编译输出：0 Error, 0 Warning
6. 烧录hex文件：Objects\Project.hex
