# 智能安防联动风扇系统 - STM32F103C8

## 项目简介
基于STM32F103C8芯片、FreeRTOS多任务架构的智能安防联动风扇系统。
在原有智能风扇（温度/人体感应自动调速）基础上，增加了人体红外远距离检测、
烟雾/可燃气体报警联动，实现"平时低速换气、无人超温全速排风、检测到烟雾立即停转"
的安防联动逻辑，并接入巴法云支持远程监控。

## 硬件配置

### 主控芯片
- STM32F103C8T6

### 外设模块
1. **AHT20/SHT30温湿度传感器**：硬件I2C1
   - SCL：PB6，SDA：PB7

2. **直流电机 + TB6612驱动模块**
   - AIN1：PA1（方向控制）
   - AIN2：PA2（方向控制）
   - PWMA：PA0（TIM2_CH1，速度控制）

3. **MQ-2气体/烟雾传感器**
   - AO：PA4（ADC1_CH4）

4. **HC-SR501人体红外传感器（PIR）**
   - OUT：PB11（数字输入）

5. **有源蜂鸣器**
   - I/O：PB12（数字输出，低电平触发）

6. **0.96寸OLED显示屏**：软件模拟I2C
   - SCL：PB8，SDA：PB9

7. **按键**
   - K1：PB14（模式切换/报警确认）
   - K2：PB13（风力调节）

8. **ESP8266 WiFi模块**：USART1
   - TX：PA9，RX：PA10

详细接线见 `接线说明.md`。

## 功能说明

### 1. 双模式控制
- **自动模式**：结合温度和人体感应联动决策（详见`功能说明.md`）
  - 有人在场：按温度分档（<26℃关闭，26~28℃低速，28~30℃中速，≥30℃高速）
  - 无人 + 温度超限(≥30℃)：全速排风降温（安防联动核心场景）
  - 无人 + 温度正常：低速换气

- **手动模式**：通过K2按键手动调节风力，循环切换：关 → 低速 → 中速 → 高速 → 关

### 2. 安防联动
- 检测到烟雾/可燃气体时，无条件立即停转电机（防止鼓风助燃），OLED闪烁报警，蜂鸣器同步鸣响
- 报警状态采用手动确认解除策略：需按K1确认现场安全后才能恢复正常运行

### 3. OLED显示
实时显示温度、湿度、运行模式、人体检测状态、风扇状态、风力档位、气体传感器读数；
报警时切换为闪烁警示画面

### 4. 远程监控
通过ESP8266接入巴法云，支持远程查看运行状态、下发开关/档位/模式切换指令

## 软件架构：FreeRTOS多任务

```
User/
├── main.c                # 初始化+创建任务+启动调度器
├── app_shared.c/h        # 共享数据结构、事件标志组、互斥量
├── FreeRTOSConfig.h      # FreeRTOS配置
├── Task_Safety.c/h       # 安防安全任务（最高优先级，烟雾监测）
├── Task_FanControl.c/h   # 风扇控制核心任务（事件标志组联动决策）
├── Task_Presence.c/h     # 人体检测任务（维护无人事件位）
├── Task_Sensor.c/h       # 温湿度采集任务（维护温度超限事件位）
├── Task_Display.c/h      # OLED显示任务
└── Task_Cloud.c/h        # 云端通信任务

Hardware/
├── Motor.c/h          # TB6612电机驱动，4档控制
├── AHT20.c/h          # 硬件I2C温湿度采集
├── Gas.c/h            # MQ-2气体/烟雾ADC采集与报警判定
├── PIR.c/h            # HC-SR501人体红外检测
├── Buzzer.c/h         # 有源蜂鸣器报警驱动
├── Key.c/h            # 按键扫描（K1/K2）
├── PWM.c/h            # TIM2_CH1 PWM输出
├── OLED.c/h           # 软件I2C OLED显示驱动
├── ESP8266.c/h        # WiFi/云平台通信
└── LED.c/h            # LED指示灯（可选）

Library/FreeRTOS/      # FreeRTOS内核源码（V202212.00，ARM_CM3端口）
```

任务划分、优先级、事件标志组联动逻辑的详细说明见`功能说明.md`。

## 编译与烧录

### 环境要求
- Keil MDK 5（ARMCC或ARMCLANG均可）
- STM32F1xx标准外设库
- FreeRTOS内核源码（已随项目附带于`Library/FreeRTOS`）

### 编译步骤
1. 用Keil打开 `Project.uvprojx`
2. 点击编译按钮（或按F7），确认0 Error 0 Warning
3. 生成的hex文件位于 `Objects/` 目录

### 资源占用参考
- Flash：约21KB（芯片总容量64KB）
- RAM：约14.5KB（芯片总容量20KB）

### 烧录方式
- ST-Link
- J-Link

## 注意事项

1. **FreeRTOS与SysTick**：SysTick已被FreeRTOS调度器接管，`System/Delay.c`改用
   DWT周期计数器实现忙等延时，不与调度心跳冲突

2. **气体报警阈值校准**：
   - MQ-2需要预热1~3分钟才能稳定输出
   - 阈值在`Hardware/Gas.c`的`GAS_ALARM_THRESHOLD`中配置，需现场校准

3. **电源供电**：
   - TB6612驱动模块需要独立电源供电（不要直接用USB供电），建议7.2V~12V
   - MQ-2、HC-SR501通常需要5V供电，注意与3.3V逻辑电平共地
   - 注意共地连接

4. **OLED接口**：
   - 确认OLED模块是I2C接口（不是SPI）
   - I2C地址默认为0x78（7位地址0x3C）

5. **PIR灵敏度/延时**：
   - HC-SR501模块上有电位器可调节触发延时和检测方式，建议设为最短延时+不可重复触发
